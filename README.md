# BuyBuzz

BuyBuzz is a MERN stack e-commerce web application.

## Technologies Used

- React.js
- Node.js
- Express.js
- MongoDB
- Mongoose
- JavaScript
- HTML
- CSS

## Features

- User Registration and Login
- Product Browsing
- Product Details
- Search and Category Filtering
- Add to Cart
- Buy Now
- Checkout
- Order Management
- Admin Dashboard
- Add and Delete Products
